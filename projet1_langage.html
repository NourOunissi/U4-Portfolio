Upon joining the company, I had to learn Windev autonomously to meet the specific needs of ongoing projects. I began by consulting the official PC Soft manual to master the basics, then supplemented my training with video tutorials on YouTube and resources available on the PC Soft website. By structuring my learning in stages, I first acquired the fundamentals and then applied my knowledge through real-world projects. When facing technical challenges, I was able to find solutions through forums and code examples. This learning process enabled me to quickly contribute to internal projects and bring real value to the company.

Exercise: Creating a Simple Task Management Application Objective: Develop a small application that allows the user to add, delete, and mark tasks as completed.

1.Creating a Windev project: Open Windev and create a new project by clicking on "New Project." Choose a classic "Windows" application, and name your project, for example, "TaskManagement." Select a local HFSQL database to store the tasks.

2.Designing the user interface: Main window (fenGestionTaches): Create a new window in the project and name it "fenGestionTaches." Add an input field to enter a new task (for example, a "Text Input Zone" field). Add a button labeled "Add Task." Create a table or list to display the added tasks, named "tableTasks." Add two additional buttons next to the task list: one for "Delete Task" and another for "Mark as Completed."

3. Creating the database:: Create a data file "Tasks" with the following fields: IDTask (Unique identifier, automatic) TaskName (Text, 100 characters) Completed (Boolean, to indicate if the task is completed)
